# Digital Forensics

## Overview

This section highlights hands-on digital forensics work completed in lab environments. My experience has focused on acquiring and validating forensic images, examining file systems and user activity, recovering deleted data, analyzing metadata, and investigating memory artifacts.

These labs helped me develop a structured approach to evidence handling and forensic analysis while reinforcing the importance of preserving data integrity throughout an investigation.

## Forensic Disk Analysis

Using **Autopsy**, I investigated forensic disk images to identify artifacts and reconstruct user activity. Analysis included:

- Recovering and examining deleted files
- Reviewing browser and search history
- Examining email artifacts
- Identifying user accounts and system information
- Reviewing installed applications and potentially relevant tools
- Locating files and artifacts relevant to an investigation
- Examining timestamps and other metadata

## Forensic Imaging and Evidence Integrity

I practiced creating forensic copies of evidence using **FEX Imager** and validating image integrity through cryptographic hashing.

This work included:

- Creating forensic copies of source images
- Recording and comparing hash values
- Verifying that forensic copies remained identical to the original evidence
- Applying evidence-preservation and chain-of-custody principles

## File Recovery and Hex Analysis

Using **HxD**, I examined data at the hexadecimal and byte level to better understand file structures and recover damaged or deleted information.

Exercises included:

- Inspecting raw hexadecimal data
- Identifying file signatures and headers
- Reassembling files from raw data
- Recovering files at the byte level
- Verifying recovered files through hashing

## Metadata Analysis

Using tools such as **ExifDataView**, I examined metadata contained within files and images to identify information that could contribute to an investigation.

This demonstrated how metadata can provide additional context regarding file creation, modification, devices, and user activity.

## Memory Forensics

I also gained experience using **Volatility** to examine memory artifacts and identify potentially suspicious processes and system activity.

Analysis included modules and techniques such as:

- `pslist`
- `psscan`
- `pstree`
- `psxview`
- `malfind`
- `apihooks`
- `dlllist`
- Loaded-module analysis

This work provided experience comparing process views, identifying hidden or suspicious processes, examining injected memory regions, and investigating loaded DLLs and hooks.
