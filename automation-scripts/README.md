Python Scripts for Productivity Automation
----------------------------------------------------

## Overview
This section highlights Python projects focused on automating repetitive tasks, processing files, generating structured output, and improving workflow efficiency.

These projects demonstrate practical use of Python for scripting, file handling, automation, input processing, and basic security-related tasks.

## Projects

### Employee Password Generator
A Python script that reads employee information from a CSV file, generates a randomized password for each employee, and writes the results to a new CSV file.

The project demonstrates:
- CSV file processing
- Random password generation
- String manipulation
- File input/output
- Workflow automation

[View Script](./JosephPatnoe_EmployeepwdGenerator.py)

### Automated File Sorting
A Python automation script that extracts files from a ZIP archive, identifies files by type, and automatically organizes them into separate directories.

The project demonstrates:
- File system automation
- ZIP archive handling
- Directory creation
- File type identification
- File movement and organization
- Python OS and shutil modules

[View Script](./JosephPatnoe_FileSorting.py)
